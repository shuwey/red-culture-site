## 二、七步流程

### 1. 史料核实（先做，且必须做）
交叉核实：作者生卒 / 初版时间·出版社 / 章节数 / 人物原型 / 事件时间线 / 课标依据。
**来源**：人民网党史频道、中央党史和文献研究院、中央纪委国家监委网站、对应纪念馆。

### 2. 教学设计三件套
- **教学目标**：语言/思维/审美/文化四维度，行为动词可观察可测
- **教学环节**：读前导读 → 读中 5 课时 → 读后展示评价
- **课堂提问**：核心问题统领 + 五级问题链（记忆→创造）+ 追问话术

### 3. 知识库网页
人物卡片 / 关系图 / 地点空间 / 事件时间轴 / 主题精神 / 史料依据。
用 SVG 手绘图表，纯前端离线可用，移动端自适应。

### 4. 大容量题库
目标：单选 120+ / 多选 30+ / 填空 50+ / 判断 50+ / 简答 30+。
**用 Python 生成器产出**，不要手写 HTML。

### 5. 回书指引（精确到章）
格式：`回书指引：……见第15章。（原书第15章）`
先搜「书名 + 每章内容概括」建章节纲 → 关键词→章号映射 → 自动拼装。

### 6. 章节考点对照表
解析 `ref` 章号 → 按章聚合 → HTML 讲义 + JSON + CSV。

### 7. 接入站点导航
改 `script.js` 的 `MODULE.books` 追加一项 → 三个页面按样式隔离规则接入 → **重跑生成器**。

## 三、五条硬性红线

### ① 版权
- 红色经典 ≠ 公共领域。合作作品保护到**最后去世作者**死后 50 年。
  《红岩》罗广斌逝 1967、杨益言逝 2017 → 保护至 **2067.12.31**。
- 全文上网/进小程序 = 侵权（信息网络传播权），"适当引用"不适用。
- 只做**转化性内容**：导读、考题、章节指引 + 极少量短引文并署名。

### ② 数据真实性
- 明确区分**文学虚构 vs 历史真实**。
- 例：甫志高是多个叛徒的艺术综合（非单一真人）；"中美合作所"是文学背景（SACO 1946.1 已撤销）。
- 与史实有出入的细节标为**思辨素材**，不作史实转述。

### ③ 前端样式隔离
- 独立页面**不引全站 `style.css`**（自带 `header{}`/`.stat`/`.tag` 会冲突）→ 引 `nav-embed.css`。
- 页面自身 `header{}` → `.page-head`；裸 `nav{sticky;top:0}` → `.pagenav` 且 top 改 48px。
- 页面必备：`#nav`、`.nav-links`、`#drawer`、`#burger`、`#user-area`。

### ④ 导航注入
- 幂等、点击跳转（不做 hover 弹窗）
- `insertAdjacentHTML("beforebegin")` **必须对锚点元素调用**（对容器会插到容器外）
- 首页"关于本站"是 `href="#footer"`，子页是 `index.html#footer`，两种都要兼容

### ⑤ 缓存破阵
- 改任一静态资源 → **全站批量递增 `?v=`**
- 上传后 `curl` 线上确认版本 → 用户硬刷新
- 新增文件单独确认已上传（否则 404）

## 四、验证方法（jsdom，不用起浏览器）

```js
const dom = new JSDOM(html, {runScripts:'outside-only', url:'http://localhost/'});
window.matchMedia = () => ({matches:false, addListener(){}, removeListener(){}});
window.eval(scriptSrc);
// 关键：jsdom 的 readyState 停在 loading，
// 不手动派发 DOMContentLoaded 则注入代码不执行，极易误判为"注入失败"
document.dispatchEvent(new window.Event('DOMContentLoaded', {bubbles:true}));
```

检查项：导航项是普通 `<a>`、href 正确、无下拉、hover 无副作用、父元素正确、
位置在"关于本站"前、幂等、点击 `defaultPrevented === false`。

## 五、加一本新书，实际操作只需 3 步

1. **跑流程 1–6**（史料核实 → 教学设计 → 知识库 → 题库 → 回书指引 → 对照表）
2. **改 `script.js` 的 `MODULE.books`**，追加：
   ```js
   { label:"书名", author:"作者 · 整本书阅读", desc:"一句话简介",
     items:[ {t:"知识库 · 人物 / 地点 / 事件", h:"..."},
             {t:"阅读题库（N 题）", h:"..."},
             {t:"章节考点对照表", h:"..."} ] }
   ```
3. **全站递增 `?v=` → 上传 → curl 验证 → 硬刷新**

落地页 `red-literature.html` 会自动列出新书（由 `renderLitIndex()` 渲染），无需手改。
