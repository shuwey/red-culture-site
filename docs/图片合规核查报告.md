## 六、可直接套用的文案

**单图角标（已由 `script.js` 自动添加）：**
```
<span class="ai-badge">AI 生成 · 艺术再现</span>
```

**站点级声明（页脚自动注入）：**
```
本站部分配图为人工智能生成的"艺术再现"图像，用于烘托历史氛围，
并非真实历史照片或纪实影像，不代表史实原貌。涉及真实历史人物与事件，
请以权威史料、纪念馆与官方发布为准。
```

**真实照片 figcaption 范例：**
```html
<figcaption>图片来源：<a href="https://commons.wikimedia.org/wiki/File:..." target="_blank" rel="noopener">Wikimedia Commons</a> · 作者 XXX · CC BY-SA 4.0</figcaption>
```

**发布前核查清单（4 问）：**
1. 这张图是否 AI 生成？→ 是则必须进 `AI_IMAGE_FILES` 白名单或显式标注。
2. 是否出现真实英烈/领导人可辨识面孔？→ 是则禁止，改用权威影像。
3. 若是真实照片，来源/授权是否可核实？→ 否则加真实出处，禁止假署名。
4. 是否可能被误读为"真实历史照片"？→ 是则加"非史实影像"免责。
