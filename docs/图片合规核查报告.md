## 三、共性问题（4 项）

1. **全站零 AI 标识**：20 个文件无一标注"AI 生成/艺术再现"，违反《人工智能生成合成内容标识办法》+ 强制性国标 GB 45438-2025（2025-09-01 施行）的显式标识要求。
2. **无站点级图片声明**：页脚/"关于"页未说明"AI 生成图均为艺术再现、非真实历史照片"，用户无从辨别。
3. **天安门双版本不统一**：`event-kaiquo.html` 用无署名 AI 版 `detail-tiananmen.png`，`place-tiananmen.html` 用带署名真实照片版 `detail-tiananmen.jpg`。同一符号两种来源，且开国大典页是更高敏感场景。
4. **`place-tiananmen.html` 署名存疑**：figcaption 写"Wikimedia Commons · 作者 Steven Kevil · CC BY-SA 4.0"，但文件是本地 `.jpg`、作者名非常规，**需核实是否真为 Wikimedia 授权图**；假署名比无署名更糟（构成误导）。

## 六、可直接套用的文案

**单图角标（加在 `<img>` 后或 `figcaption`）：**
```
<figcaption class="ai-note">AI 生成 · 艺术再现 · 非史实影像</figcaption>
```
（配套 CSS：小号、浅灰、居中，如 `font-size:.8em;color:#8a7a6a;`）

**站点级声明（放"关于"页 + 页脚，覆盖全站）：**
```
本站部分配图为人工智能生成的"艺术再现"图像，用于烘托历史氛围，
并非真实历史照片或纪实影像，不代表史实原貌。涉及真实历史人物与事件，
请以权威史料、纪念馆与官方发布为准。
```

**发布前核查清单（4 问）：**
1. 这张图是否 AI 生成？→ 是则必须标"AI 生成·艺术再现"。
2. 是否出现真实英烈/领导人可辨识面孔？→ 是则禁止，改用权威影像。
3. 若是真实照片，来源/授权是否可核实？→ 否同则加真实出处，禁止假署名。
4. 是否可能被误读为"真实历史照片"？→ 是则加"非史实影像"免责。
