## 三、发布到线上（CloudBase 静态托管）

CLI `tcb` 3.8.0 已安装但**未登录**（`tcb login` 需浏览器授权）。改用 CloudBase MCP：

**第 1 步 · 绑定环境**（不绑定会报 `ENV_REQUIRED`）

```
auth(action="set_env", envId="cloud1-d0g0aq0bl2cfbcbdf")
```

环境有两个：`cloud1-d0g0aq0bl2cfbcbdf`（站点在用）、`red-culture-d2gfectm806fb6d1d`（未用）。

**第 2 步 · 上传**

```
manageHosting(
  action="upload",
  localPath="/Users/shuwei/WorkBuddy/2026-08-23-20-29-48/red-culture-site",
  cloudPath="/",
  ignore=[".git/**", ".workbuddy/**", "generated-images/**", "docs/**",
          "scripts/**", "cloudfunctions/**", "appeal-attachments/**",
          "**/*.py", "**/*.md", "**/*.mp4", "**/*.mjs", "**/*.zip",
          "骑楼海报*.png", "**/detail-tiananmen-old.png",
          ".gitignore", "**/quiz_raw.json"]
)
```

### 三个必知要点

1. **`cloudPath` 必须传 `"/"`** —— 传 `""` 会被判为参数缺失，报 `HOSTING_UPLOAD_FAILED`。
2. **返回的 `successCount: 1 / totalFiles: 1` 是按目录计的**，不代表只传了 1 个文件。别被误导。
3. **视频默认跳过** —— `assets/videos/` 两个 mp4 共 19MB，改动时才重传；先比字节数确认。

## 四、改完静态资源：必须先破阵再上传

CDN 缓存 `s-maxage=600` / 浏览器 `max-age=300`，改了文件不换版本号等于没改。

```python
# 全站批量递增版本号
re.sub(r'(<script src="script\.js)(?:\?v=[0-9a-zA-Z]+)?"', r'\1?v=<新版本>"', s)
re.sub(r'(<link rel="stylesheet" href="nav-embed\.css)(?:\?v=[0-9a-zA-Z]+)?"', r'\1?v=<新版本>"', s)
```

**版本号必须全站统一递增**，不能只改部分页面。当前版本：`20260828e`。

## 五、发布后校验（HTTP 200 不等于内容最新）

CDN 会返回旧内容，**必须 curl 正文核对**：

```bash
BASE="https://cloud1-d0g0aq0bl2cfbcbdf-1471653339.tcloudbaseapp.com"

# ① 版本号（应与本地一致）
curl -s "$BASE/index.html" | grep -o 'script\.js?v=[0-9a-zA-Z]*' | head -1

# ② 题库题数
curl -s "$BASE/hongxing-quiz.json" | python3 -c "import sys,json;print(len(json.load(sys.stdin)['questions']))"   # 291
curl -s "$BASE/hongyan-quiz.json"  | python3 -c "import sys,json;print(len(json.load(sys.stdin)['questions']))"   # 229

# ③ 页面标题
curl -s "$BASE/hongxing-chapter-map.html" | grep -o '<title>[^<]*</title>'

# ④ 导航数据
curl -s "$BASE/script.js" | grep -o 'label: "[^"]*"' | head -6
```

最后**提醒用户硬刷新（Cmd+Shift+R）**。
