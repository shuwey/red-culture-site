# 红色文化传播网 · 增量 PRD（v2）

> 本文档只描述**变更/新增部分**，不重复既有功能。基线：现有纯静态站点（原生 HTML/CSS/JS，无构建工具、无框架）。
- Language: 中文
- Programming Language: 保持原生 HTML/CSS/JS（不引入构建工具）；云能力通过 CDN 引入 `@cloudbase/js-sdk`，必要时配合 CloudBase 云函数
- Project Name: red-culture-site-v2
- 云环境: CloudBase `cloud1-d0g0aq0bl2cfbcbdf`（已开通）

---

## 一、产品目标（≤3 条）

1. **让历史"可对话"**：上线站内「红色历史 AI 问答助手」，基于站内已有人物/地点/事件语料回答问题，答不上时明确说"资料未收录"，不编造史实。
2. **补全信息架构**：消除所有 `#` 占位链接，事件、关于、联系、常见问题均可到达详情页，站点形成完整闭环。
3. **建立用户身份与成长闭环**：注册登录后可保存知识考核成绩、查看个人记录，提升回访动力。

---

## 二、用户故事

- 作为访客，我想在任意页面点击右下角悬浮的 AI 助手，用自然语言提问"杨靖宇是在哪里牺牲的"，以便快速获得基于站内史料的一句话答案和原文链接。
- 作为学生用户，我想注册并登录账号，以便把每次红色知识考核的成绩保存下来、看到自己的进步。
- 作为登录用户，我想在导航栏看到我的昵称/头像并能一键退出，以便确认当前登录状态。
- 作为浏览者，我在时间轴上点"遵义会议"，想进入一个图文并茂的事件详情页，以便深入了解背景、经过和意义。
- 作为想引用资料的教师，我想访问"关于本站 / 史料来源"页，以便确认内容的严肃性和出处。
- 作为有疑问的访客，我想在"常见问题"页找到"内容是否免费""AI 回答可信吗"等解答，以便放心使用。
